# i2net – Image-to-Network Decoder  
### 🔄 Reverse Companion to net2i

i2net decodes **RGB images** generated by **net2i** back into **structured CSV network data**.  
It fully reconstructs IPv4, IPv6, MAC, numeric, string, and timestamp fields using the bijective metadata saved by net2i.

🧩 **Important:**  
i2net only supports images generated by **net2i**. Images from other encoding tools will not decode correctly.

# 🚀 Features

- 🔁 **Full Reversal of net2i Images** – Converts RGB pixel blocks back into CSV rows  
- 🌐 **IPv4 + IPv6 Support**  
- 📅 **Timestamp Reconstruction**  
- 🧠 **Adaptive Decoding**  
- 💡 **Supports all net2i Data Types**  
- 📊 **Batch Decoding**  
- 🛡️ **Corruption Handling**  
- 🔧 **IPv4/IPv6 Metadata File Support**

# 🎯 Basic Usage

```python
import i2net

results = i2net.decode(
    data_directory='data',
    output_csv='decoded_output.csv'
)
```

---

# ⚙️ Advanced Usage

```python
results = i2net.decode(
    data_directory='traffic_images',
    output_csv='output.csv',
    types_file_ipv4='ipv4_schema.json',
    types_file_ipv6='ipv6_schema.json',
    verbose=True
)
```

# 🔍 Single Image Decoding

```python
import i2net

values = i2net.decode_single("data/ipv6_0.png", is_ipv6=True)
values = i2net.decode_single("data/ipv4_3.png")  # auto-detects IPv4
```

# 📊 Decoding Logic

| Data Type      | Storage Method        | Decoding Process                          |
|----------------|------------------------|--------------------------------------------|
| Float/Integer  | 2 RGB pixels (6 bytes) | IEEE-754 float reconstruction              |
| IPv4           | 8 RGB pixels           | 4 floats → dotted decimal                  |
| IPv6           | 6 RGB pixels           | 16 bytes → IPv6 address                    |
| MAC Address    | 4 RGB pixels           | Hex bytes → MAC format                     |
| Timestamp      | 12 RGB pixels          | Rebuilds `[Y,M,D,H,M,S]`                   |
| String         | 2 RGB pixels           | Hash value → string representation         |
